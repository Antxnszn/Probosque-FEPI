# Dominio: Cierre

## Alcance
Finiquito administrativo, órdenes de pago y conclusión formal de trámites.

## Responsabilidades
- Generación de órdenes de dispersión o pago tras dictamen favorable.
- Recepción de comprobaciones fiscales y recibos de finiquito.
- Cierre definitivo de expedientes y archivo histórico.

## Dependencias
- `app/modules/dictaminacion`: Dictamen aprobado como prerrequisito obligatorio.

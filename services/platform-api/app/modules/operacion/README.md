# Dominio: Operación de Campo

## Alcance
Coordinación general de actividades de campo, brigadas y calendario interinstitucional.

## Responsabilidades
- Planificación y agenda operativa de brigadas de supervisión.
- Coordinación logística con subsistemas especializados (PROBOSQUE).
- Monitoreo de cobertura geográfica institucional.

## Dependencias
- `app/integrations/probosque`: Consulta de brigadas, asignaciones y técnicos activos.

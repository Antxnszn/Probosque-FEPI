# Dominio: Convocatorias

## Alcance
Administración de convocatorias públicas para apoyos y programas institucionales de FEPI.

## Responsabilidades
- Publicación de reglas de operación y calendarios de recepción.
- Configuración de criterios de elegibilidad y requisitos documentales.
- Apertura y cierre de periodos de recepción de solicitudes.

## Dependencias
- `app/security`: Permisos de administración de programas.

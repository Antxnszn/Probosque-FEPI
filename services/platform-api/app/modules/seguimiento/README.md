# Dominio: Seguimiento

## Alcance
Control de compromisos, convenios de asignación y cronogramas de ejecución.

## Responsabilidades
- Seguimiento al cumplimiento de metas físicas pactadas.
- Registro de visitas de supervisión y coordinación de campo.
- Generación de reportes de avance periódico por programa.

## Dependencias
- `app/integrations/probosque`: Verificación de auditorías subsecuentes.

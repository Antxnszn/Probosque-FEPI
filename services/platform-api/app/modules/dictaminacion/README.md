# Dominio: Dictaminación

## Alcance
Evaluación técnica, normativa y jurídica de solicitudes registradas.

## Responsabilidades
- Evaluación de expedientes contra las reglas de operación de la convocatoria.
- Consumo del cálculo de subsidio y elegibilidad de PROBOSQUE como insumo técnico.
- Emisión de dictámenes administrativos de aprobación o rechazo justificado.

## Dependencias
- `app/integrations/probosque`: Consulta de `SubsidyDecision`, resultados técnicos y evidencias.

# Dominio: Expedientes

## Alcance
Gestión integral de expedientes administrativos y folios únicos de trámite.

## Responsabilidades
- Generación y asignación de folios institucionales.
- Carga y resguardo de documentación solicitante en almacenamiento seguro.
- Vinculación de referencias externas hacia predios y auditorías de PROBOSQUE.

## Dependencias
- `app/integrations/probosque`: Consulta de referencias cartográficas y predios.

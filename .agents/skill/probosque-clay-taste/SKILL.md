# Probosque Clay Taste

Define the visual identity, artistic sensibility, color harmony, and typographic voice for **PROBOSQUE (Protectora de Bosques del Estado de México)**. This Taste Skill prevents generic AI/RAG developer templates and replaces them with an approachable, tactile, botanical **Cardless Claymorphism** aesthetic tailored for citizens, forest engineers, and public servants.

## When to Use

- Establishing the look, feel, color tokens, and font stack for any PROBOSQUE web application, dashboard, citizen portal, or internal assistant
- Auditing UI code generated by Antigravity or other coding agents to eliminate developer-console cliches
- Choosing colors, shadows, typography, or copywriting tone for forestry, environmental, and government program interfaces

## 1. Visual North Star: Botanical Claymorphism Without Clutter

PROBOSQUE is a human-centered environmental program, not a cyberpunk terminal. The visual language combines two references:

1. **Tactile Claymorphism (Friendly & Sculpted):** Interactive elements (buttons, toggles, search wells, floating docks, and key indicators) feel like smooth, hand-molded natural clay and river stones. Depth comes from dual inner shadows (top-left warm highlight + bottom-right deep moss shade) and diffused ambient elevation, making the application welcoming and intuitive.
2. **Open Editorial Respiration (No Card Saturation):** Inspired by modern editorial agriculture and sustainability layouts, information flows directly on a warm limestone-sand canvas (`#F2EFE9` / `#D9D1B8`) using generous whitespace, soft organic focal zones, and large expressive figures rather than trapping every paragraph or metric inside repetitive rectangular cards.

### Color Harmony Rules

- **Ban Corporate Navy & Cold Slate:** Never use `#002B66`, `#0B0F19`, `slate-*`, `indigo-*`, or `blue-*` anywhere in the application.
- **80 / 15 / 5 Proportion:**
  - **80% Warm Breathable Canvas:** `#F4F1EA` and `#D9D1B8` with `#1B2A24` typography.
  - **15% Botanical Structure:** `#B9C8B2`, `#6B8B78`, and `#355044` for sculpted zones and navigation.
  - **5% Differential Pop:** `#E0643A` (Terracota Resina) to draw immediate, friendly attention to the main action on screen.

## 3. Typography System: Warm, Humanist & Zero Code Fonts

Technical monospace fonts alienate users and make government environmental tools look like raw database logs.

### Approved Font Stack

- **Display, Headings & Big Metrics (`--font-display`):** `'Outfit'`, `'Plus Jakarta Sans'`, or `'Fraunces'` (for editorial warmth). Use light-to-medium weights (`300`, `400`, `500`) on large titles and large expressive numbers (`+24%`, `14,500 ha`) so they feel airy and refined, never blocky.
- **Body, Navigation & Controls (`--font-sans`):** `'Plus Jakarta Sans'` or `'DM Sans'`. Open apertures, friendly curves, and high legibility at `15px`-`16px`.
- **Numeric Alignment:** Always apply `font-variant-numeric: tabular-nums` on statistics and counters using `--font-display` or `--font-sans`.

### Strict Typography Prohibitions (The `image_4676e0.png` Ban)

1. **FORBIDDEN — Monospace / Code Fonts:** Never import or apply `JetBrains Mono`, `Fira Code`, `Roboto Mono`, `Courier`, `ui-monospace`, or Tailwind's `font-mono` anywhere in the UI.
2. **FORBIDDEN — Tracked-Out All-Caps Numbered Banners:** Never generate headers like `01 · ESTADO DEL CORPUS MULTIPROYECTO` in uppercase tracked-out text on a dark bar. Write natural, human Spanish headings in sentence case: *"Estado actual de los proyectos forestales"*.
3. **FORBIDDEN — Technical AI Jargon Labels:** Replace robotic system terms (`Corpus Global`, `Multiproyecto`, `10 Docs`, `GLOBAL ACTIVO`, `RAG Engine`) with warm domain language (`Acervo Forestal del Estado`, `10 expedientes consultables`, `Consulta ciudadana y técnica`).

## 4. Anti-Saturation & Cardless Philosophy

To keep the interface intuitive and free of visual saturation:

- **No Box-Inside-Box Grid of Cards:** Do not wrap every metric, project item, or prompt suggestion inside a bordered rectangle or repetitive 3-column card grid.
- **Use Open Typographic Columns & Recessed Clay Wells:** Group related metrics in an open horizontal flow separated only by generous padding (`32px`-`48px`). When a group of controls needs containment (such as a search bar or filter bar), place them inside a single soft **Recessed Clay Well** (`#D9D1B8` with soft inner shadow) rather than stacking multiple individual cards.
- **Maximum 3 Distinct Component Groups Per View:** Every screen must have one clear focal point (e.g., the conversational assistant well or the active reforestation map/summary), one quiet navigation dock, and one open-air data strip.
